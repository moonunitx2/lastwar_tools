# Last War Alliance Tracker

A PHP-powered alliance and poll tracking website for Last War.

## 🔧 Features

- Live leaderboard with sorting, likes, and history
- Poll system with results tracking
- Admin panel for creating new polls
- Discord login support

## 🧰 Requirements

- PHP 7.4+
- MySQL
- Composer

## 🚀 Setup

1. Clone the repo and run the setup:

```bash
bash setup.sh
```

2. Fill in MySQL credentials when prompted.

3. Optionally import the schema when asked.

4. Done!

## 🔐 Security

Use `sanitize.sh` before pushing your code to GitHub to remove sensitive credentials.

## 🗃️ MySQL Schema

Check `schema.sql` for full table structure.

## 📦 Composer Dependencies

- thiagoalessio/tesseract_ocr
- league/oauth2-client
- vlucas/phpdotenv
- openai-php/client
- twilio/sdk
- guzzlehttp/guzzle
